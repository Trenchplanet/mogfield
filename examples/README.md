# Examples

`clips/` holds the sample takes the app preloads. The two `placeholder-*`
clips are synthetic stand-ins generated with ffmpeg; replace them with your
own consented test takes (walk, turn, dance, talk, product in hand).

Add before/after pairs under `outputs/` as `NN-name-before.mp4` /
`NN-name-after.mp4`. Add as many as you like.
